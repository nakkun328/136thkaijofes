# ライブ配信 構成メモ（ミニステージ）

## 去年の課題

- 構成：一眼カメラ --(HDMI 10m)--> キャプボ --> PC（OBS）--> 校内 Wi-Fi --> YouTube
- カメラを非常階段に置いたため、校内 Wi-Fi の上りが遅く、YouTube の配信が途切れ途切れになった
- HDMI 10m で、Wi-Fi がぎりぎり届く場所まで PC を寄せて配信していた
- カメラからミニステージまで距離があり、音声の取り方が未定

## 今年の構成案

```
[ワイヤレスマイク送信機（ステージ横）] ～ワイヤレス 25-30m～ [受信機] --> カメラのマイク端子
カメラ --(HDMI 10m)--> キャプボ --> PC（OBS）--(Wi-Fi)--> モバイルルーター（楽天 SIM）--> YouTube
```

- 音声はカメラ経由で HDMI に乗るため、映像とのずれがほぼ起きない
- 回線を校内 Wi-Fi から配信専用のモバイル回線に替えるので、PC の置き場所の自由度が上がる

## 回線

- 楽天モバイル（Rakuten最強プラン、データ無制限）＋モバイルルーター
- 候補機種：**Rakuten WiFi Pocket 5G**（2026年3月発売、5G Sub6・プラチナバンド対応、連続通信 約9時間）
  - 他社 SIM も試すなら SIM フリーの Rakuten WiFi Pocket 2C
- 注意点
  - パートナー回線（au ローミング）エリアでは高速通信が月 5GB まで → 会場が楽天回線エリアか確認
  - 長時間配信ではモバイルバッテリー／USB 電源につなぐ
  - 直射日光・熱を避けて日陰に置く
  - 配信の通信量の目安：1時間あたり約 2〜4GB

## 音声

1. まず音響担当（別部署）に、ミキサーの余り出力（AUX OUT / REC OUT など）から配信用の音をもらえるか確認する
2. 無理なら、配信専用のワイヤレスマイクを用意する（会場スピーカーとは別系統）

### ワイヤレスマイク候補

| 製品 | 特徴 |
|---|---|
| **DJI Mic 3**（第一候補） | 2.4GHz / 5.8GHz を自動切替で混雑に強い。送信機に内部録音あり。2TX+1RX+充電ケースで 5 万円前後 |
| RODE Wireless GO（第3世代） | より安価。公称 260m。32bit float 内部録音。2.4GHz のみ |

- ステージ〜カメラは 25〜30m、間に障害物なし → クリップ型で届く距離
- 送信機・受信機とも観客の頭より高い位置に置く
- 送信機はスピーカーよりステージ寄りに置く（スピーカーの響いた音を拾わないように）
- 内部録音を有効にして、配信が途切れたときのアーカイブ用の保険にする
- 電池切れ対策（出し物の合間に充電する段取り）
- カメラにマイク端子がない場合は、受信機を USB-C で PC に直接つなぎ、OBS で同期オフセットを調整する

## OBS 設定の目安

- 720p / 30fps / 2500〜3500kbps
- YouTube の遅延設定は「通常」（低遅延にしない。バッファが増えて途切れにくい）
